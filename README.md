# Booki - Trouvez votre hébergement pour des vacances de rêve
![alt text](images/logo/Booki.png)

Ceci est le premier projet de ma formation de développeur web. L'objectif était de transformer une maquette Figma en un site de planification de vacances fonctionnel et entièrement responsive.

## 📝 Description
Booki permet aux usagers de trouver des hébergements et des activités dans la ville de leur choix. Le projet met l'accent sur l'intégration rigoureuse du design et la fluidité de l'expérience utilisateur sur tous les supports.

## 🚀 Compétences acquises
* **HTML5 & CSS3** : Structuration sémantique et mise en forme avancée.
* **Responsive Design** : Utilisation des Media Queries pour adapter le site sur Mobile, Tablette et Desktop.
* **Flexbox** : Alignement et organisation des éléments de manière dynamique.
* **Figma** : Lecture et interprétation d'une maquette professionnelle.

## 🛠️ Outils utilisés
* **Visual Studio Code** (Éditeur de texte)
* **FontAwesome** (Pour les icônes)
* **Google Fonts** (Pour la typographie)
